LOCAL DEV BUILDS A LEGAL RAG THAT ACTUALLY SHOWS ITS WORK

By Staff Writer · Special to The Daily Bugle

Aryan Mandapati put together a legal RAG pipeline that turns U.S. statutes into clear rules you can check. Every rule points back to a real section of law. If the model tries to invent a citation, the system flags it.

You pick a domain, jurisdiction, and rule type. The app retrieves matching provisions (BM25 by default, dense retrieval if you want it), then drafts rules only from that text. Each run leaves a full trace in Langfuse and a local JSONL file, so you can see retrieval, generation, and grounding checks step by step.

Built with Python, Streamlit, Claude, and pytest. It also runs offline with an extractive fallback, no API keys required.
